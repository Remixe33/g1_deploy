# 机器人模块

机器人模块描述与任务无关的机器人结构和安装属性，供任务档案组合使用。

## 当前模块

- `g1_stock.json`：标准头部安装，`head_back_deg: 0`。
- `g1_head_back_20deg.json`：整个头部后仰 20°，当前用于 door 仿真。

## 头部后仰实现

仿真场景生成器将 `head_link` 绕躯干 +Y 轴旋转，枢轴为躯干系 `[0,0,0.320] m`：

- 头部安装点和深度相机使用同一旋转枢轴；
- 头部质量、质心和惯量并回躯干重新计算，总质量不变；
- 不新增关节，`nu` 保持 29，控制器和关节布局不变；
- 深度相机朝向随头部一起变化，避免相机绕躯干原点旋转而进入肩部遮挡区域。

头部后仰来源与参数记录见 [模型与资产来源](../../../ORIGIN.md)。Parkour 未在该视角下训练，表现需另行验证；DWaQ 不使用深度。

实机头部属于独立电机系统，不在 29 电机低层链路内。若实机也改变头部或相机安装，必须同步更新相机外参，不能仅靠仿真配置推断实机安装。
